Ditch the Keyboard — Gesture Recognition for Touch-Free Gaming Experiences

Project information

  • Category: Human and Computer Interaction, Web, AI
  • Project timeline: May 2025
  • Medium Blog: Click here to read my blog on this project

👤👤👤👤 4 Person Team Project

  • Touch-free web app that allows the user to play Braininess using hand gestures
  • Key Functionalities:
  • - Used MediaPipe Canned Gesture Classifier for pre-made gestures
  • - Implemented custom gestures using MediaPipe Hand Landmarks
  • - Implemented the following gestures:
  • • Point Left, Thumb Right, Victory Sign, Point Up, Open Palm, Thumbs Up, Thumbs Down
